IMPLEMENTATION DETAILS TO PRESERVE
- Codec edits retain unknown/opaque plugin data. UUID normalization applies
  only to schema identifiers; Native FX references stay coherent.
- Clearing clip.regionOwnerID and other known optional fields removes the
  old JSON values rather than resurrecting them on save.
- History is bounded and preserves the nearest undo/redo entries; document
  changes commit atomically and preserve transport when appropriate.
- Duplication copies complete stored FX states and regenerates entity IDs.
  Capturing live external-plugin state still needs the eventual plugin host.
- prepareRecordingProject returns a document plus transient armedTrackIDs;
  it does not silently replace an unsaved session.
- Device endpoints currently support at most 32 channels; the REC factory's
  128-track limit is a document limit, not a hardware claim.
- Save As to another parent remains rejected until media packaging is ready.
