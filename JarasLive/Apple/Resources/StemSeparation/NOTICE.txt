CatStemSeparation 5 — CatLive stem separation workers

The separation worker uses Demucs 4.0.1 and Meta's pretrained HTDemucs 6-source
model, under the MIT license (see Demucs-LICENSE.txt).
https://github.com/facebookresearch/demucs
Model: 5c90dfd2-34c22ccb.th (htdemucs_6s).
Outputs: vocals → Vocal; drums → Drum; bass → Bass; guitar → Guitar;
other + piano → Other. Piano is retained, not discarded.

Ultimate Vocal Remover GUI was used as an architectural reference.
https://github.com/Anjok07/ultimatevocalremovergui
The UVR GUI, name, artwork and denoise weights are not included.

The relocatable CPython distributions are provided by python-build-standalone:
https://github.com/astral-sh/python-build-standalone
CPython and dependency licenses are retained in the bundled runtime, including
site-packages/*.dist-info and the individual packages' license directories.
Runtime dependencies and exact versions: scripts/catstem-requirements.lock.
Audio is processed locally. No audio or project data is uploaded.

CatLive now exposes separation only as an offline action for audio items.
The resulting five files play as ordinary audio; no model is run in the FX chain.
macOS uses the bundled PyTorch/Demucs runtime (CPU on Intel, CPU/MPS on Apple
Silicon), Windows uses the bundled CPU runtime, and native iPad uses the bundled
Core ML model. The removed realtime MLX plugin is not required by this feature.
