    Receive / Transmitter / Project Sync

    Conexão redundante

    Configure automaticamente dois computadores ligados por RJ45, inclusive usando adaptadores USB–Ethernet. O Wi‑Fi continua livre para internet.

    Etapa 1

    Escolha o adaptador

    Verificando
    Conecte o cabo RJ45 nos dois computadores.

    Etapa 2

    Preparar a rede

    A Hook Center cria automaticamente um IP exclusivo neste computador. A rede não define mestre nem escravo e pode ser usada pelo Receive/Transmitter ou pelo Project Sync.

    Aguardando configuração.

    Depois

    Conectar o VS Hook

    1. Repita esta configuração na Hook Center do outro computador.
    2. Escolha Receive/Transmitter somente no menu da extensão, quando quiser esse modo.
    3. No Project Sync, os dois computadores são equivalentes: comandos iniciados em qualquer um deles serão sincronizados.
    4. A conexão continua totalmente local e não precisa de internet.

    Gerenciamento

    Portas criadas

    0 pares

    Nenhuma porta criada pela Hook Center.

    Envie MIDI para uma ponta e receba na outra. As portas temporárias permanecem até serem removidas, o serviço MIDI reiniciar ou o Windows reiniciar.

    Windows 10

    Alternativa recomendada

    O Hook MIDI será exclusivo do Windows 11. No Windows 10, utilize o loopMIDI para criar portas MIDI virtuais.

    macOS

    Driver IAC nativo

    Sem instalação
    1. Abra o Estúdio MIDI pelo botão acima. Se aparecerem dispositivos de áudio, pressione Command+2 ou use Janela → Mostrar Estúdio MIDI.
    2. Dê dois cliques em Driver IAC.
    3. Marque O dispositivo está online.
    4. Adicione ou renomeie um barramento para Hook MIDI e clique em Aplicar.
    5. Use o barramento como saída no programa emissor e como entrada no programa receptor.
